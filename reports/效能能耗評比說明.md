# 五大效能能耗評比分析

## 📊 新增功能

### 1. 性能比較圖表
**檔名**: `multi_platform_performance_comparison.png`
- 推理速度比較
- 總處理時間
- 平台排名
- 相對速度比率
- 性能統計表

### 2. 能耗效率評比圖表 ⚡ (新增)
**檔名**: `efficiency_power_comparison.png`

包含五大評比維度：

#### ① 能耗效率排名 (TPS/W)
- **指標**: 每瓦推理速度 (Tokens/秒/瓦)
- **意義**: 數值越高，能源利用效率越好
- **最佳**: T4 (0.846 TPS/W)

#### ② 算力利用效率 (TPS/TFLOP)
- **指標**: 每TFLOP推理速度
- **意義**: 顯示硬體算力的實際轉換效率
- **發現**: T4效率最高，GB10效率極低

#### ③ 每百萬Token電費成本
- **指標**: 處理一百萬個Token的電費 (假設$0.10/kWh)
- **意義**: 實際運營成本
- **最低**: T4 ($0.033)
- **最高**: GB10 ($0.422)

#### ④ 年度碳排放量
- **指標**: 24/7運行一年的碳排放 (kg CO₂)
- **意義**: 環保指標
- **最環保**: T4 (307 kg CO₂/年)
- **最高排放**: GB10 (4,380 kg CO₂/年)

#### ⑤ 五維綜合評比雷達圖
結合五個維度的綜合評比：
- **推理速度**: 絕對性能指標
- **能效比**: 能源效率
- **算力效率**: 硬體利用率
- **成本優勢**: 經濟性
- **環保指數**: 碳排放表現

## 🔧 技術細節

### 能效計算公式

1. **能效比 (TPS/W)**
   ```
   能效比 = 平均TPS ÷ TDP功耗
   ```

2. **算力效率 (TPS/TFLOP)**
   ```
   算力效率 = 平均TPS ÷ FP32算力
   ```

3. **每百萬Token成本**
   ```
   日耗電量 = (TDP × 24) ÷ 1000 kWh
   日Token數 = TPS × 60 × 60 × 24
   成本 = (日耗電量 × 電費) ÷ (日Token數 ÷ 1,000,000)
   ```

4. **年度碳排放**
   ```
   年耗電量 = 日耗電量 × 365
   碳排放 = 年耗電量 × 0.5 kg CO₂/kWh
   ```
